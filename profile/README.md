# syntrophic.ai

The world allows for significantly more forms of organisation than we are able
to imagine; we are limited by an imagination that only recognises what it has
already seen. One question drives this work: **how do we design systems that
generate order and organisation at scale?** The referential pattern is
**syntrophy**: each part transforms what it receives and returns something
that leaves the whole system with greater capacity to continue.

## The work

**[mycelium](https://github.com/syntrophic-ai/mycelium)** — the foundation of
a shared language for organisation patterned on syntrophy: first principles,
the ontology that grows from them, and the law governing how any of it may be
spoken about. A language, not a platform.

## Status

Prose, not software. Nothing federates; no receipt between real organisations
has ever been issued; nothing has been measured, because nothing has run. The
repository's README states the limitations in full, and its `decisions/`
record every ruling — including why its history is a single commit.

## A note on the words

*Syntrophic* means feeding-together — the microbiological relation where one
organism's metabolic products sustain another. It is not *syntropic*, and the
two are never interchangeable here.

*Mycelium* is a bounded topology analogy. It carries nothing about intention
or co-operation, and no property of fungal networks is offered as an argument
for anything.
