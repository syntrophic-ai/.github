# syntrophic.ai

Each organisation runs its own **office**. Offices **collaborate** across
organisations. Value flows between them are **proved**, not claimed.

## Two things

**Syntrophic OS — the node.** The digital office an organisation runs: its own
data, its own inference, its own decisions about what it exposes. A tracking
fork of [Paperclip](https://github.com/paperclipai/paperclip) (MIT).

**Mycelium AI — the network.** How nodes discover each other, hand off work
across an organisational boundary, and sign a receipt for it that the other side
can verify independently.

The node works alone. The network is opt-in.

## Status

Early, and spec-first. The specifications land before the code that implements
them. Nothing federates yet.

## A note on the words

*Syntrophic* means feeding-together — the microbiological relation where one
organism's metabolic products sustain another. It is not *syntropic*, and the
two are never interchangeable here.

*Mycelium* is a bounded topology analogy. It carries nothing about intention or
co-operation, and no property of fungal networks is offered as an argument for
anything.
